# Deploy on Render

This app needs **Web + Worker + PostgreSQL + Redis**.

## Fast path (Blueprint)

1. Push/use repo `main`: https://github.com/TheBoss845/dex-global-sourcing-ai  
2. In [Render](https://dashboard.render.com) → **New** → **Blueprint**  
3. Connect the GitHub repo and select branch `main`  
4. Render reads `render.yaml` and creates:
   - `dex-web` (public site)
   - `dex-worker` (pipeline)
   - `dex-postgres`
   - `dex-redis`
5. When prompted, fill these **secret** values (same on Web; Worker needs the AI/search ones too):

| Variable | Example |
|----------|---------|
| `TAVILY_API_KEY` | `tvly-...` |
| `OPENAI_API_KEY` | `sk-...` |
| `RESEND_API_KEY` | `re_...` |
| `EMAIL_FROM` | `DEX Sourcing <noreply@your-domain.com>` |
| `APP_BASE_URL` | `https://dex-web.onrender.com` (your real Web URL) |

`AUTH_SECRET` is auto-generated by the blueprint.

6. After first deploy finishes, open the Web URL → `/api/health` should return `"status":"ok"`.  
7. Sign in with an **@dex.com** email → check inbox for the verification link → **Find Suppliers**.

## Manual setup (if you skip Blueprint)

### A. Create Postgres
Render → **New** → **PostgreSQL** → name `dex-postgres`

### B. Create Redis / Key Value
Render → **New** → **Key Value** → name `dex-redis`  
(Internal connections only is fine)

### C. Web service
- **New** → **Web Service** → this repo, branch `main`
- Runtime: Node
- Build command: `bash scripts/render-build.sh web`
- Start command: `bash scripts/render-start-web.sh`
- Health check path: `/api/health`

### D. Worker service
- **New** → **Background Worker** → same repo
- Build command: `bash scripts/render-build.sh worker`
- Start command: `bash scripts/render-start-worker.sh`

### E. Environment variables
On **both** Web and Worker, set:

```bash
NODE_ENV=production
DATABASE_URL=<from Render Postgres>
REDIS_URL=<from Render Key Value>
TAVILY_API_KEY=tvly-...
OPENAI_API_KEY=sk-...
AI_ENABLED=true
OPENAI_MODEL=gpt-4o-mini
RESULT_LIMIT=10
ARTIFACT_STORAGE=local
ARTIFACT_LOCAL_PATH=.artifacts
```

Web only (also needed for sign-in email):

```bash
AUTH_SECRET=<long-random-string>
APP_BASE_URL=https://YOUR-WEB.onrender.com
RESEND_API_KEY=re_...
EMAIL_FROM=DEX Sourcing <noreply@your-domain.com>
```

## Notes

- Only **@dex.com** emails can request/complete verification.
- If `APP_BASE_URL` is empty, the app falls back to Render’s `RENDER_EXTERNAL_URL`, then the request host.
- Free/starter plans may sleep; first request can be slow.
- After changing env vars, trigger a **Manual Deploy**.
- Resend requires a verified sending domain for `EMAIL_FROM`.
- Do **not** put API keys in GitHub — only in Render env vars.
